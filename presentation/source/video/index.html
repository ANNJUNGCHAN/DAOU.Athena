앱을 사용하는 흐름

23개 기능 · 장면을 눌러 이동
화면 구성과 출처

홈페이지 cinematic-motion.css를 복사해 로드하고 1600×1000 앱 좌표와 우측 대화 배치를 적용했습니다. 현재 기능과 원본 차트는 별도 DOM 어댑터로 연결했으며, 홈페이지 React 화면 전체를 그대로 실행한 것은 아닙니다. 차트·관계망·백테스트의 원본 영역은 사용자가 제공한 시연영상에서 가져왔습니다. 기능 예시는 홈페이지와 앱 코드로 대조했습니다. 주문, 도구 등록, 기억 수정은 영상용 재현이며 실제 계정에 실행하지 않습니다.

기능별 연결 장면 6편은 새 AI 생성 영상입니다. 모니터 장면에는 실제 시연 차트를 합성했습니다. 도시의 연결선·빛·전략 경로는 기능을 설명하는 연출이며 실제 앱 결과가 아닙니다.
