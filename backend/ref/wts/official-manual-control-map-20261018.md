# 키움 WTS 공식 설명서 기반 제어 맵

조사일: 2026-10-18  
범위: 키움증권 공식 `kiwoom.com` 도움말의 **PC > 웹트레이딩** 섹션에서 확인한 서비스 소개·이용방법·주요화면 세 페이지와 그 페이지에 실제로 포함된 이미지·링크만 사용했다. 이 문서는 그 제한된 공식 자료가 말하는 사실과 ATHENA의 실제 화면 검증을 분리한다.

## 공식 설명서가 확인하는 범위

| 주제 | 공식 근거 | ATHENA 제어에 적용할 결론 |
| --- | --- | --- |
| 서비스·접속 | [서비스 소개](https://www.kiwoom.com/h/help/channel/VHelpWtsInfoView)는 WTS가 설치 없이 브라우저에서 실행되고, PC·태블릿·Mac을 지원하며, 국내주식·ETF·ETN을 거래 가능 상품으로 제시한다. | 확장 프로그램의 대상 origin은 `https://wts.kiwoom.com/`으로 한정한다. 브라우저 종류·화면 크기는 실행 전 관찰해야 하며, 도움말만으로 동일한 DOM 구조를 가정하면 안 된다. |
| 로그인·화면 크기 | [이용방법](https://www.kiwoom.com/h/help/channel/VHelpWtsUseView)은 `wts.kiwoom.com` 접속 경로를 안내한다. PC는 공동인증서·간편인증을, Mac/태블릿은 간편인증을 지원한다고 설명하며, 일부 태블릿은 로그인 뒤 우측 상단에서 화면 비율을 조정할 수 있다고 한다. | 공식 자료는 화면 비율 조정 기능의 존재만 확인한다. 실제 제어 가능 여부와 현재 레이아웃은 로그인한 화면에서 별도로 관찰·검증한다. |
| 주요 화면 | [주요화면](https://www.kiwoom.com/h/help/channel/VHelpWtsMajorView)은 메인화면, 호가, 시장종합, 뉴스, 순위분석, 빅데이터를 공식 주요 화면으로 제시한다. | 이 여섯 화면은 화면 조사 우선순위 후보이다. 각 화면은 실제 탭/라우트/팝업 여부를 로그인 세션에서 개별 관찰·기록해야 한다. |
| 도움말 구조 | 조사한 웹트레이딩 안내의 하위 메뉴는 서비스 소개·이용방법·주요화면 세 페이지다. 세 페이지의 본문 링크·내장 문서·PDF 링크도 확인했으며, 이 범위에서 추가 WTS 매뉴얼은 발견하지 못했다. | 이 조사 범위만으로는 전체 WTS 기능 명세를 만들 수 없다. 화면 제어 명세는 실측 캡처와 명시적 사후조건으로 보강한다. |

## 공식 페이지의 이미지·링크 확인

- 서비스 소개에는 본문 이미지·추가 문서 링크가 없었다.
- 이용방법에는 접속, 로그인, 화면크기, 삼성인터넷·Chrome·Safari의 홈 화면 바로가기 이미지를 확인했다. 이미지에 적힌 조작 순서는 “로그인 후 화면크기 확인 → 화면크기 선택 → 화면크기 변경”이며, Chrome 바로가기 그림은 “WTS 접속 → 우측 상단 메뉴 → 홈화면에 추가 → 이름 확인 → 추가 → 아이콘 확인” 순서다.
- 주요화면에는 메인화면·호가·시장종합·뉴스·순위분석·빅데이터의 여섯 공식 화면 이미지가 있다. 메인화면 도해에는 `시장종합`, `차트`, `뉴스`, `예약주문` 상단 항목과 시세/호가·종목목록·주문·차트가 함께 보이지만, 이 그림은 화면 구성 예시이며 안정적인 DOM·영역·자동화 명세가 아니다.
- 세 페이지에서 발견된 본문 링크는 서로를 가리키는 세 안내 페이지뿐이었다. 확인한 본문에는 PDF, 별도 도움말 문서, iframe·embed 링크가 없었다.

## 조사한 공식 세 페이지가 정하지 않는 세부 제어 항목

다음은 위에서 실제로 확인한 세 페이지의 본문·이미지·본문 링크에 조작 절차 또는 지원 조건이 없었다. 이것은 키움의 다른 문서 전체에 해당 내용이 없다는 주장 아니다. 이 조사 범위의 빈칸을 추정으로 채우지 않는다.

| 항목 | 공식 문서 상태 | ATHENA 처리 원칙 |
| --- | --- | --- |
| P1/P2/P3 영역명·영역 경계 | 미기재. 이는 ATHENA의 화면 분류명이다. | 현재 화면의 식별 가능한 제목·활성 탭·컨테이너를 먼저 관찰하고, 불일치하면 실행을 막는다. |
| 종목 검색·검색 결과 선택 | 미기재 | 종목 코드/명 입력과 결과 선택은 별도 실측 시나리오와 종목 일치 사후조건이 필요하다. |
| 차트 열기, 일/주/월/분 주기 | 미기재 | 활성 탭과 실제 기간 표시를 실행 전후 비교할 수 있을 때만 한 번 클릭한다. |
| 보조지표·거래량 | 미기재 | 각 지표의 표시명, 설정창, 적용 상태를 확인하는 전용 실측 시나리오가 필요하다. |
| 뉴스 필터·기사 열기 | 주요화면에 뉴스 이미지가 있으나 조작 절차는 미기재 | 기사 선택, 외부 링크, 새 창은 현재 화면의 결과를 확인하는 별도 시나리오가 필요하다. |
| 사이트맵·전체 메뉴 | 공식 도움말에는 도움말 자체의 전체 메뉴가 있을 뿐 WTS 내부 사이트맵 동작은 미기재 | WTS 내부 메뉴는 실측 목록으로 별도 관리한다. |
| 팝업·새 창·독립 화면 | 미기재 | 새 `window`/탭/iframe가 생기면 현재 창의 식별·목적·사후조건을 확인하는 시나리오가 필요하다. |
| 브라우저 보안 프로그램·자동화 허용 범위 | 미기재 | 이 세 페이지로는 인증·계좌·주문 기능의 자동화 허용 범위를 판단할 수 없다. |

## 실제 화면 검증과의 구분

이 문서의 “공식 설명서가 확인하는 범위”와 이미지·링크 절은 공식 도움말만으로 확인한 사실이다. `P1/P2/P3`, 종목 코드, 활성 차트 주기, DOM 선택자, 팝업 여부, 그리고 모든 ATHENA 실행 영수증은 **공식 문서의 주장으로 간주하지 않는다**.

현재 별도 실측에서 확인된 항목은 차트의 일·주·월·년 전환과 주봉 복원, 차트 설정의 세 탭과 취소, 뉴스, 종목시세 하위의 일별주가·체결추이·거래원·투자자, 상세 종목검색 모달이다. 이 목록은 실제 런타임 관찰 결과이며, 위 공식 세 페이지에 대한 인용이 아니다.

이 조사 턴은 로그인, 인증, 계좌 조회, 주문을 수행하지 않았다. 기존 ATHENA 제품 범위는 별도로 적용한다. 즉 실계좌 조회는 범위에 포함되고, 모의투자 주문은 티켓별 사용자의 확인이 있을 때만 다루며, 자격증명 자동화·실계좌 주문·자동 매매는 범위 밖이다. 이 범위 구분은 키움 공식 도움말에서 도출한 정책이 아니다.

## 추가 공식 참고자료의 버전 경계

키움 다운로드 서버의 [[5000] WTS 주식종합](https://download.kiwoom.com/hero4_help_new/5000.htm)은 공식 자료이지만, 본문이 “2016.12.30경” 서비스 종료에 따른 JAVA WTS 사용자를 위한 화면이라고 명시하고 영웅문4 WTS·JAVA 메뉴를 설명한다. 따라서 이 자료는 과거 명칭과 화면 개념을 해석할 때만 참고하며, 현재 HTML WTS의 선택자·화면 구조·기능 존재·제어 절차에 대한 증거로 사용하지 않는다.

## 다음 조사 순서

1. 공식 주요화면 여섯 항목을 실제 WTS의 현재 탭·화면과 대응시킨다.
2. 종목 검색, 차트 주기, 보조지표/거래량, 뉴스, 전체 메뉴를 각각 독립 시나리오로 캡처한다.
3. 각 시나리오에 실행 전 조건, 허용 클릭 수, 사후조건, 팝업/새 창 차단 규칙을 기록한다.
4. 설명서에 없는 기능은 실측 검증 전까지 대화 명령의 후보로만 보여 주고 실행하지 않는다.
