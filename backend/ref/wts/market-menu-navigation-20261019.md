# WTS 시장 메뉴 직접 탐색 검증

조사일: 2026-10-19

대상: 실제 Chrome에서 사용자가 이미 연 로그인 WTS 탭의 사이트맵과 P1 시장 분석 영역

구조화 자료: [market-menu-navigation-20261019.json](market-menu-navigation-20261019.json)

사이트맵을 열어 표시 상태를 기다린 뒤 그룹 안의 정확한 버튼을 한 번 클릭하고, 사이트맵 modal이 닫힌 것을 확인한 다음 P1의 활성 그룹·자식 또는 최상위 활성 탭을 읽었다. 이 절차로 시장 분석 메뉴 25개의 화면 전환을 확인했다.

이 결과는 **일반 브라우저 도구가 실제 WTS UI를 직접 탐색한 증거**다. ATHENA 확장 action 지원, 화면에 표시된 시장 데이터의 정확성, LAYA 학습용 gold episode, 전체 WTS 조사 완료를 뜻하지 않는다.

## 검증 절차와 범위

각 항목에 같은 절차를 적용했다.

1. 사이트맵을 열고 modal이 표시될 때까지 기다린다.
2. 사이트맵 `dl` 그룹 안에서 정확한 버튼을 찾아 한 번 클릭한다.
3. 사이트맵 modal이 숨겨졌는지 확인한다.
4. P1의 `li.depth.active`에서 그룹과 자식 활성 텍스트를 읽는다. 빅데이터는 같은 구조의 자식 목록이 없어 최상위 활성 텍스트를 읽는다.

모든 25개 항목에서 기대한 활성 상태와 modal 닫힘을 확인했다. 계좌값, 표 행, 화면 header, 입력값, 원시 HTML은 읽거나 저장하지 않았다.

| 구분 | 확인 수 | 사후조건 |
|---|---:|---|
| P1 그룹 + 자식 활성 | 24 | 기대한 그룹과 자식 텍스트가 모두 일치 |
| P1 최상위 활성 | 1 | `실시간종목조회순위` 선택 뒤 `빅데이터` 활성 |
| modal 닫힘 | 25 | 각 클릭 뒤 사이트맵 modal 숨김 |
| 실패 | 0 | 기대 상태 불일치 없음 |

## 복원 상태

검증이 끝난 뒤 P1을 `순위분석 → 전일대비등락률상위`로 복원했다. 임시 viewport override도 해제해 `498 × 677`로 돌아온 것을 확인했다.

## 증거 경계

- 메뉴 클릭과 활성 상태 확인은 해당 진입 경로가 관찰 시점에 동작했다는 증거다. 조회 결과의 값·시점·정확성을 검증하지 않았다.
- 이 조작은 ATHENA 확장과 Native Messaging 실행기를 통하지 않았다. 확장 지원으로 집계하려면 등록 action, 실행 전 상태, 실제 확장 실행, 후조건, receipt와 실패·복구 검증이 별도로 필요하다.
- 25개 기록은 검토된 LAYA 학습 episode가 아니다. 사용자 지시, 후보 집합, observation revision, action receipt, 다음 observation과 defer/복구 label이 연결되기 전에는 gold 자료로 사용하지 않는다.
- 사이트맵에서 보이지 않는 header 새 창, context menu, 계좌·주문, iframe, canvas와 다른 화면 상태가 남아 있으므로 W0·W1·W2 완료로 판정하지 않는다.

사이트맵의 전체 발견 분모는 [WTS 사이트맵 실시간 UI 발견 목록](sitemap-inventory-20261019.md)에 기록한다. 공식 도움말에서 확인한 서비스 범위는 [키움 WTS 공식 설명서 기반 제어 맵](official-manual-control-map-20261018.md), 앞선 제한된 일반 브라우저 조작은 [WTS 직접 브라우저 제어 검증](direct-control-validation-20261018.md)에서 구분한다.
