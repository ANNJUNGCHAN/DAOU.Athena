# WTS 직접 브라우저 제어 검증

조사일: 2026-10-18

대상: 로그인된 `https://wts.kiwoom.com/`의 메인 화면 P1·P3 영역과 직접 연 독립 창

목적: ATHENA 확장 동작을 늘리기 전에 일반 HTTPS 브라우저 제어로 안정적인 선택 기준과 사후조건을 확인한다.

이 기록은 [키움 WTS 공식 설명서 기반 제어 맵](official-manual-control-map-20261018.md)의 공식 자료 조사와 별개인 실측 결과다. 공식 도움말 세 페이지와 포함 이미지를 확인했으며, 그 제한된 범위에서는 내려받는 별도 매뉴얼을 찾지 못했다. 이는 키움의 다른 문서 전체에 매뉴얼이 없다는 뜻이 아니다. 공식 도움말은 화면의 존재와 서비스 범위를 확인하는 데 사용했고, 아래 DOM 구조와 동작 결과는 로그인된 WTS에서 직접 관찰했다.

## 제어 경계

일반 HTTPS WTS 페이지는 브라우저 자동화 도구로 관찰·클릭할 수 있었다. Chrome 내부 페이지와 ATHENA 확장 side panel은 이 도구로 조작할 수 없으며, 다른 통로나 개발자 프로토콜로 우회하지 않았다. 따라서 아래 직접 제어 결과는 새 ATHENA 확장 action의 구현·검증 증거가 아니다.

P1·P3는 각각 `article.article-area`로 먼저 범위를 제한한 뒤 내부 요소를 찾았다. P3에서 `종목시세` 버튼은 하나였고, 주 탭은 종목시세·차트·뉴스로 식별됐다. P1에서는 순위분석·빅데이터 버튼을 영역 안에서 식별했다. 전역 텍스트나 화면 좌표만 사용하지 않았다. 로그인, 인증, 계좌 조회, 주문, 실제 종목 선택은 수행하지 않았다.

## 확인한 직접 제어

| 영역 | 실행한 조작 | 확인한 사후조건 | 판정 범위 |
| --- | --- | --- | --- |
| 차트 기간 | 주봉 상태에서 월봉 → 년봉 → 주봉 복원 | 각 단계에서 대응 기간 버튼의 class가 활성 상태로 변경 | 월·년 전환과 주봉 복원 직접 확인 |
| 차트 설정 | P3 설정 열기 → 기준선 → 배경 → 취소 | `.setting_modal.top_setting_modal` 표시, `#chart`·`#guideLine`·`#background` 탭 관찰, 취소 뒤 modal visibility가 false, 주봉 유지 | 설정 탐색과 무변경 취소 확인; 저장·파라미터 변경은 미실행 |
| 뉴스 | 뉴스 탭 열기 | 뉴스 탭 활성, 날짜·시간·제목·종목·제공자 헤더 표시, P3 내부 iframe 0개 | 목록 틀 확인; 기사 열기·외부 이동은 미실행 |
| 종목시세 | 일별주가·체결추이·거래원·종목별투자자를 차례로 열기 | 각 하위 메뉴 활성 상태와 대응 헤더 표시 | 화면 전환 확인; 조회값은 읽거나 기록하지 않음 |
| 상세종목검색 | 검색 modal 열기, 화면 크기 조정 후 ETF → 전체 → 닫기 | `.vue-window-modal` 표시, ETF 활성 class 확인, 전체 선택 뒤 닫기에서 modal visibility가 false | 시장 분류 선택과 정상 닫기 확인; 종목 선택은 미실행 |
| 시장종합 독립 창 | 헤더의 `시장종합` 클릭 | 새 WTS 창의 관찰된 path가 `/marketinfo`, KOSPI·KOSDAQ·거래량 등 헤더 표시 | 새 창 생성과 기본 DOM 상태 확인; 조회값·iframe 내용은 미확인 |
| 차트 독립 창 | 헤더의 `차트` 클릭, 일봉 → 주봉 → 일봉 | 새 WTS 창의 관찰된 path가 `/chart`, `#ChartDIV_Canvas` 표시, 주·일 활성 class 순차 확인 | 독립 창과 기간 전환 확인; canvas 내부 조작은 미실행 |
| P1 분석 | 순위분석 상태 관찰 → 빅데이터 → 순위분석 | 빅데이터와 복원한 순위분석의 활성 class, 대응 헤더 표시 | 두 탭의 활성 상태 확인; 순위 데이터 값은 읽거나 기록하지 않음 |
| 최종 복원 | 차트 탭과 주봉으로 복귀 | 차트 canvas 표시, 주봉 활성, 검색·설정 modal 비표시 | 후속 검증을 위한 안전한 최종 상태 확인 |

차트 설정에는 차트·지표, 기준선, 배경 탭이 있었다. 차트 유형으로 캔들, 라인, 바, P&F, 삼선전환도를 관찰했다. 지표 목록은 18개였고 가격이평, 거래량, 거래량이평, MACD, RSI 등이 포함됐다. 목록의 존재만 확인했으며 지표를 적용하거나 설정값을 저장하지 않았다.

상세종목검색 modal에는 전체, 코스피, 코스닥, 거+코, NXT, ETF, ETN 분류가 있었고 iframe은 없었다. modal heading의 숫자형 ID는 실행마다 달라질 수 있어 제어 식별자로 사용하지 않는다.

## 화면 밖 modal에서 얻은 검증 규칙

초기 브라우저 viewport는 `486 × 665`였고 검색 modal의 관찰된 사각형은 `x=692.8`, `y=443`, `w=330`, `h=450`이었다. 이 상태에서 ETF와 닫기 호출 자체는 반환됐지만, 활성 상태나 닫힘을 확인하지 못했으므로 성공으로 집계하지 않았다. viewport를 `1400 × 1000`으로 처음 확장했을 때 CSS viewport는 `1108 × 788`이었고, ETF 활성 class와 닫은 뒤 visibility false를 확인했다. 이후 실제 Chrome에 맞춘 `1800 × 1200` 설정에서는 CSS viewport가 `1440 × 960`임을 확인했다. 모든 확인 뒤 viewport는 `486 × 665`로 복원했다.

이 현상은 브라우저 자동화 도구의 viewport와 실제 Chrome 창 크기 차이에서 발생했다. 현재 ATHENA 제품 어댑터는 modal이 DOM에 존재하고 표시 스타일과 크기가 유효하면 차단 상태로 취급하므로, 이번 관찰만으로 확장 프로그램의 offscreen modal 차단 결함을 입증하지 않는다.

modal은 `count() == 0` 또는 요소 존재 여부만으로 닫힘을 판정할 수 없다. Vue가 닫힌 요소를 DOM에 남길 수 있으므로 닫기 사후조건은 visibility false로 확인해야 한다. 클릭 호출의 정상 반환도 화면 변화의 증거가 아니다.

## 독립 창과 P1 관찰

헤더의 `.haeder-menu` 안에서 `시장종합`과 `차트`를 각각 클릭했을 때 기존 메인 탭이 바뀐 것이 아니라 새 WTS 창이 열렸다. 두 창은 도구가 반환한 새 tab ID와 실제 관찰된 path로 구분했다. 미리 정한 URL로 성공을 추정하지 않았다.

시장종합 창의 path는 `/marketinfo`였다. KOSPI, KOSDAQ, 거래량 등의 헤더와 `조회` 버튼 하나, 기관 선택 요소를 관찰했다. canvas는 없었고 same-origin iframe 하나가 있었지만 목적과 내부 동작은 조사하지 않았다. iframe의 존재는 제어 가능 증거가 아니다.

차트 창의 path는 `/chart`였다. 독립 차트의 canvas는 `#ChartDIV_Canvas`였고 메인 P3 차트의 `#Main04002Chart_Canvas`와 구분됐다. 초기 일봉 활성 상태에서 주봉을 눌러 주봉 활성 상태를 확인하고, 다시 일봉을 눌러 일봉 활성 상태와 canvas visibility를 확인했다. 이 결과는 독립 창에 대한 일반 브라우저 제어 증거이며 ATHENA 확장 지원 증거가 아니다.

P1에서는 관찰 시 순위분석이 활성 상태였고 `전일대비등락률상위` 화면이 보였다. 빅데이터를 클릭한 뒤 빅데이터 활성 상태와 순위·종목명·순위변동·기준시점주가 등의 헤더를 확인했다. 이어 순위분석을 직접 클릭해 활성 상태가 복원된 것을 확인했다. P1 내부 canvas와 iframe은 모두 0개였다. 최초 상태가 어떤 이전 동작으로 만들어졌는지는 추정하지 않는다.

검증을 위해 직접 연 `/marketinfo`와 `/chart` 두 자식 창만 닫았다. 최종적으로 기존 메인 WTS `/` 탭만 남겼고 P3는 차트·주봉 활성, 설정·검색 modal 비표시 상태였다.

| 차트 열기·일봉·주봉 | 조작 절차 없음 | 차트 탭과 기간 활성 상태 확인 | `차트 열어줘`, `일봉으로`, `주봉으로`의 좁은 정상 경로 검증 |
| 월봉·년봉 | 조작 절차 없음 | 월봉 → 년봉 → 주봉 복원 검증 | 미구현 |
| 차트 설정·지표 | 조작 절차 없음 | 설정 탭·차트 유형·지표 목록과 취소 검증 | 미구현 |
| 뉴스 | 주요 화면으로 제시 | 탭·목록 헤더·P3 iframe 부재 확인 | 미구현 |
| 종목시세 하위 화면 | 조작 절차 없음 | 네 하위 메뉴의 활성 상태와 헤더 확인 | 미구현 |
| 상세종목검색 | 조작 절차 없음 | 시장 분류 ETF·전체와 닫기 검증 | 미구현 |
| 시장종합 독립 창 | 주요 화면으로 제시 | 새 `/marketinfo` 창과 기본 헤더·구조 확인 | 미구현 |
| 차트 독립 창 | 메인 화면의 상단 차트 항목과 주요 화면 예시에서 확인 | 새 `/chart` 창, 고유 canvas, 일봉 ↔ 주봉 확인 | 미구현 |
| 순위분석·빅데이터 | 주요 화면으로 제시 | P1 빅데이터 활성과 순위분석 복원 확인 | 미구현 |

공식 자료의 범위와 출처는 [공식 설명서 기반 제어 맵](official-manual-control-map-20261018.md)에, 현재 확장 영수증은 [차트 파일럿 검증 기록](chart-pilot-validation-20261018.md)에 기록한다. 직접 브라우저 검증 결과를 LAYA 학습 정답이나 확장 기능 완료로 자동 승격하지 않는다.

## 어댑터로 옮길 때의 규칙

향후 각 동작은 action manifest에 고정된 선택 범위와 실행 전·후 조건을 함께 정의한다.

| 후보 동작 | 선택 기준 | 실행 전 조건 | 사후조건 |
| --- | --- | --- | --- |
| 차트 월봉·년봉 | P3 article + 차트 탭 + 명시적 기간 버튼 이름 | P3 차트 활성, 차단 modal 없음, 대상 버튼 활성 가능 | 대상 기간 버튼 활성, 같은 종목·탭·창·문서 유지 |
| 차트 설정 탐색 | P3 차트의 설정 버튼 + modal class + 안정적인 탭 ID | 차트 활성, 설정 modal 없음 | 대상 탭 활성 또는 취소 뒤 modal visibility false, 기간 유지 |
| 뉴스 열기 | P3 article + 뉴스 탭 이름 | P3 식별 성공, 동일 이름 후보가 하나 | 뉴스 활성과 예상 헤더 표시 |
| 종목시세 하위 화면 | P3 article + 종목시세 활성 + 하위 메뉴 이름 | 종목시세 활성, 후보 하나 | 대상 메뉴 활성과 예상 헤더 표시 |
| 상세종목검색 분류 | modal class + 공개 시장 분류 이름 | modal visibility true, 차단 상태 없음 | 대상 분류 활성; 닫기는 visibility false |
| 독립 창 열기 | `.haeder-menu` + 고유 버튼 이름 | 메인 WTS 탭 식별, 같은 이름 후보 하나 | 새 tab ID, 같은 origin, 기대 path, 고유 화면 표식 확인 |
| P1 분석 전환 | P1 article + 순위분석·빅데이터 버튼 이름 | P1 식별 성공, 대상 버튼 하나 | 대상 버튼 활성과 예상 헤더 표시 |

숫자형 동적 ID, 전역 동일 텍스트, 절대 좌표는 선택자로 사용하지 않는다. 실행 전에는 후보 수·현재 탭·modal 차단 상태를 확인하고, 한 번 클릭한 뒤 활성 class·헤더·canvas·visibility 같은 사후조건을 다시 읽는다. 조건이 모호하거나 바뀌면 실행을 보류한다.

소스 검증에서는 오프라인 감사 14/14, 로컬 실행기 테스트 51/51, offscreen modal 회귀를 포함한 확장 테스트 58/58이 통과했고 별도 검토 결과는 APPROVE였다. 이는 테스트와 소스 검토 결과다. 새 확장 action, 버전, 설치본은 추가하지 않았다.

이 문서가 확인하는 것은 P1·P3와 직접 연 시장종합·차트 창의 제한된 제어 방법이다. 전체 WTS, P0·P2, 다른 새 창, 기사 본문, canvas 내부 그리기·클릭, iframe 입력, 계좌·인증·주문, 로컬 AI 계획, LAYA 학습 완료를 의미하지 않는다.
