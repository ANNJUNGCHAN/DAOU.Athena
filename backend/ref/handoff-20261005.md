## 새 컴퓨터 준비

```powershell
git clone --branch codex/laya-runtime-handoff-20261005 https://github.com/ANNJUNGCHAN/DAOU.Athena.git
cd DAOU.Athena
npm ci --prefix app
node app/node_modules/electron/install.js
Push-Location backend
uv sync
Pop-Location
node backend/ref/card-ui-handoff-20261003/resume.mjs
```

Windows, Git, Node.js/npm, Python 3.11 이상, uv를 먼저 설치한다. 이미 저장소가 있다면 로컬 변경을 보존한 뒤 `git fetch origin`, `git switch codex/laya-runtime-handoff-20261005`, `git pull --ff-only`를 실행하고 의존성 설치를 진행한다. 원래 컴퓨터의 node_modules나 Python 가상환경을 복사하지 않는다.

Codex에서 저장소 폴더를 열고 다음을 입력한다.

> AGENTS.md와 backend/ref/handoff-20261005.md, handoff-20261005-review.md를 읽고 작업을 이어서 실행해. LAYA runtime 인계 변경을 먼저 확인하고 미검증·실패 항목을 유지해. 카드 UI를 재개할 때는 원래 PLAN.md의 Paper 101개·실제 앱 94개 상태 목표와 같은 카드 최대→축소→재최대화 검증을 유지하고 목표를 다시 설정해.

Git pull과 resume.mjs는 Codex나 앱을 자동 실행하지 않는다. 앱 실행은 `npm --prefix app start`다. 새 컴퓨터에서 모델 공급자 로그인과 필요한 API 연결을 직접 설정한다. `.env`, 인증 값, 사용자 프로필, 대화 DB, 실제 금융 화면은 공개 저장소에 포함하지 않는다.

LAYA runtime의 별도 deployment/model 파일과 실행 환경은 Git 소스만으로 준비되지 않는다. `backend/athena_api/config.py` 및 `laya/runtime.py`, `laya/worker.py`의 검증 계약을 읽고 새 컴퓨터의 경로·deployment SHA·Python 실행 환경·device를 설정한다. 현재 컴퓨터의 경로 또는 인증 토큰을 그대로 복사하지 않는다. 학습 모델이나 외부 런타임 성공을 이번 소스 업로드만으로 검증했다고 표시하지 않는다.
