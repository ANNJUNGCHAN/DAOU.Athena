# Graph Memory

> 2026-10-12 동반 요약본. 웹사이트의 정본은 `lib/tech-articles.ts`의 정적 HTML과 목차 메타데이터입니다. 이 Markdown은 런타임 렌더링에 사용하지 않습니다. 전체 그림·주석·소스 링크는 [웹 기술문서](/tech/02-investment-memory)에서 확인하세요.

발표의 “금리 때문에 은행주에 관심 생겼어”는 설명 예시입니다. Graph Memory는 관심 대상과 이유를 원문 출처·시점에 연결해 나중에 “왜 은행주에 관심이 생겼지?”라는 질문에서 근거를 다시 조회합니다. 사용자 발언과 AI가 해석한 관계는 구분합니다.

대화 관심, 체결, 보유는 서로 다른 출처와 식별자를 유지합니다. 계좌에서 확인한 보유 기록은 계정·종목·수량과 연결되며, 대화의 “10주 샀어요”를 확인된 보유 사실로 바꾸지 않습니다.

현재 레코드와 append-only 변경 이력을 함께 남깁니다. 출처 위치, 시점, 원문 지문, 리비전을 보존해 현재 값과 변경 과정을 분리합니다.

대화 추출은 EXTRACTED·INFERRED·AMBIGUOUS를 구분합니다. 잘못된 JSON, 중복 키, 요청 결합 불일치, 원문 지문 불일치는 거절합니다. 동일 대상 판정은 별칭·이름·이웃 관계를 비교하되 종목과 투자자 프로필 노드의 텍스트 유사도 자동 병합을 제외합니다.

추론과 모호한 결과는 확인된 투자 사실이 아닙니다. 출처나 계좌 정보가 없으면 수량을 만들어 내지 않습니다.
